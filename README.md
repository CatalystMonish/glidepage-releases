# GlidePage downloads

Downloads for **GlidePage for Mac**: any website, one smooth 4K scroll video.

- **Download:** [GlidePage.dmg](https://github.com/CatalystMonish/glidepage-releases/releases/latest/download/GlidePage.dmg) (Apple Silicon, macOS 12 or later, signed and notarized by Apple)
- **License:** GlidePage needs a license key to run. Get one at [glidepage.app](https://glidepage.app).
- **Help:** support@glidepage.app

## Installing

1. Open the DMG and drag GlidePage to Applications.
2. Open GlidePage from Applications.
3. Paste your license key (it starts with `GLIDEPAGE-`) and click **Activate**.
